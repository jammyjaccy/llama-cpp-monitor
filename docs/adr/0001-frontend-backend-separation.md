# 前后端分离，API 为唯一通信面

监控应用拆为两个独立工程：后端（Python/FastAPI，含调度器与监控引擎）与前端（Vue 3 + Vite + Element Plus，独立构建）。前端只通过 REST API 与后端通信，不直接访问 SQLite 或引擎；构建产物由 FastAPI 静态托管，最终仍是一个进程对外服务。

**考虑过的方案**：FastAPI + Jinja2 服务端渲染单体（零构建、部署最简）。

**为什么分离**：用户明确要求系统架构分前端和后端；前端需要配置界面、分页表格、任务状态刷新等交互，独立前端工程比模板渲染更易维护。代价是引入 Node 构建链，接受。
